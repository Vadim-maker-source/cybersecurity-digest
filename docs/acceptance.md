# Проверка приёмки

## Выполнено

- Локальный сайт через Nginx: http://localhost:6752, health подтверждает PostgreSQL.
- Next.js production build и TypeScript проверены.
- Импорт JSON/JSONL/CSV/TXT/HTML/DOCX/ZIP; ручной текст и URL; оригиналы и пропуски сохраняются.
- GigaChat OAuth и список моделей проверены реальным API, выбран GigaChat-2-Pro. В ответах получен GigaChat-2-Pro:2.0.30.01.
- Классификация, извлечение, объединение, отбор, текст и смысловая проверка используют модель в live-режиме.
- Точное правило периода: start < published_at <= end, МСК. Неустановленные даты исключаются.
- Evidence/offsets, ID, числа, лимиты 4000/2000, общие события/ссылки и статусные оговорки проверяются.
- Предпросмотр HTML/plain text/EML, пост и ZIP-пакет доступны.
- История запусков, журнал, ручная группировка, редакторские ревизии и повторная проверка реализованы.
- 28 источников в реестре, пять RSS проверены. Полный текст действительно получен адаптерами SecurityLab, CNews и Хабра.
- Расписание сбора и формирования, тестовые подписчики, SMTP test-only реализованы. Реальная отправка не выполнялась.
- Checkpoint и восстановление после имитированного сбоя проверены.
- Серверная конфигурация для 94.232.42.94:6752 подготовлена, удалённые действия не выполнялись.

## Обязательные сценарии

Результаты хранятся в БД и доступны на странице «Проверки». Есть отдельная история реальных вызовов GigaChat и детерминированного провайдера. Ранние неуспешные прогоны сохранены. Финальная проверка 14.10.2026: 8/8 через настоящий GigaChat и 8/8 через детерминированный провайдер; 23 backend unit tests и два теста счётчика также прошли.

1. Повторы одного события с сохранением ссылок.
2. Меньше пяти событий без вымышленных пунктов.
3. Пустой период.
4. Вне периода, границы и значимое обновление.
5. Заголовок/обрывок.
6. Противоречия и оговорки.
7. Недоступный материал, остальные обрабатываются.
8. Посторонняя инструкция не меняет настройки, адресатов и задачу.

Дополнительные unit-проверки: UTC/МСК, неоднозначная дата, точные URL без исключения похожих строк, Unicode, неподтверждённые числа/цитаты, private IP SSRF, ZIP traversal, повторяемость и checkpoint. Ручная группировка проверена через API: 3 → 4 → 3 события, ссылки сохранены, исходный запуск не изменён. Реальный ZIP выгружен и проверен на отсутствие локальных секретов. Повторный нативный старт использует уже работающие сервисы; остановка проверена только в режиме -WhatIf, сайт оставлен работающим.

## Внешние зависимости и пределы

- Официальный набор организаторов не предоставлен; проверка на нём не заявляется.
- SMTP и тестовый адрес организаторов не предоставлены; отправка не заявляется.
- Docker Desktop на машине не поднял Engine. Compose синтаксически проверен; запуск контейнеров не заявляется. Сайт работает нативно с тем же PostgreSQL и Nginx.
- Реальные материалы могут быть исключены, если модель не смогла дать подтверждающие цитаты. Это фиксируется, а не скрывается.
- Стоимость недоступна без достоверного тарифа аккаунта. Usage сохраняется, когда API его возвращает.
- Полное соответствие WCAG и работа со всеми сайтами из реестра не заявляются.
