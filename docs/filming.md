# Показ проекта без отдельного сервера

Сайт работает на компьютере команды. Бесплатный SSH-туннель localhost.run выдаёт публичную HTTPS-ссылку. Компьютер должен оставаться включённым и подключённым к интернету. Это временный способ показа: адрес может изменяться, гарантии доступности нет. Постоянное размещение требует отдельного хостинга.

## Запуск Windows

В корне проекта выполните:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File infra/scripts/start-filming.ps1
```

Нужны установленные Python 3.12, Node.js, PostgreSQL 18 и OpenSSH; зависимости и закрытый `.env` задаются по README. Интерфейс запускается в production-режиме на внутреннем порту 6760, Nginx остаётся на 6752. Это позволяет сохранить другое приложение на порту 3000.

Текущая публичная ссылка выводится в окне и сохраняется в `work/public-site-link.txt`. После смены адреса этот файл обновляется. После обрыва соединения процесс повторяет подключение. Повторный запуск не создаёт второй процесс публикации. Окно не закрывайте; для остановки публикации нажмите Ctrl+C. Сервисы сайта продолжают работать локально.

## Что показать

1. Полный выпуск: события, последствия, оговорки и ссылки на оригиналы.
2. «Почему выбрано»: объяснения отбора.
3. «Письмо» и «Короткий пост»: согласованные форматы одного выпуска.
4. В кабинете `/editor`: сбор, журнал, проверка и редактирование.

Главная страница получает выпуск на сервере и отображает его до загрузки клиентских скриптов. Ссылки на форматы также работают при их задержке. Черновики с ошибками не попадают в публичную выдачу. Сохранившийся исторический выпуск показывает свой исходный период, а не выдаётся за новости текущих суток.

GigaChat и SMTP используют ключи из `.env`. Почтовая отправка остаётся ручной и требует утверждения. Туннель не публикует PostgreSQL и внутренние порты. Вход, CSRF и защищённые cookies сохраняются; для HTTPS-публикации задайте `COOKIE_SECURE=true`.

## Постоянное размещение

Для существующего Docker Compose можно выбрать VPS с Ubuntu 24.04, 2 vCPU, 4 ГБ RAM и SSD от 40 ГБ. Это рекомендуемая стартовая конфигурация для небольшого показа, не результат нагрузочного теста. Например, Beget поддерживает root-доступ и Docker: https://beget.com/ru/vps. Цену и доступность региона нужно подтвердить при заказе; подписка в рамках восстановления не оформлялась.

Файлы серверного HTTPS-развёртывания пока привязаны к прежнему IP. Перед переносом потребуется заменить адрес в Nginx, Compose, скриптах сертификата и `PUBLIC_BASE_URL`; слепой запуск прежнего deploy-скрипта на новом сервере не подходит.

Документация временного туннеля: https://localhost.run/docs/ и https://localhost.run/docs/forever-free/.
