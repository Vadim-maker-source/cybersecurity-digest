# КиберСводка

**[Открыть работающий сайт](https://94.232.42.94:6752/)** — просмотр дайджестов без регистрации. Резервный вариант показа с компьютера: [запуск для съёмки](docs/filming.md).

Редакционный кабинет для ежедневного дайджеста кибербезопасности. Читает RSS и публикации, определяет тематику, объединяет сообщения, отбирает максимум пять событий за сутки и готовит письмо и короткий пост со ссылками на оригиналы.

Стек: Next.js 16, FastAPI, PostgreSQL 18, SQLAlchemy, GigaChat, Docker Compose, Nginx.

Главная страница открыта без регистрации: последние 20 проверенных выпусков, события и последствия, ссылки на источники, обоснования отбора, письмо и короткий пост. Доступны копирование и скачивание текста. Неутверждённый выпуск явно помечается как предпросмотр. Показываются только реальные выпуски с успешными проверками; после редактирования черновик скрыт до повторной проверки.

Текущие дата и время синхронизируются с сервером и показываются по Москве. Открытая страница проверяет новые выпуски раз в минуту и при возвращении во вкладку. У архивных выпусков сохраняются исходные даты. Контрольное время в редакторе обновляется автоматически; ручной ввод фиксирует выбранную дату, кнопка «Сейчас» возвращает текущую. После перерыва ежедневный сбор обрабатывает текущие сутки, пропущенные дни подряд не переигрываются.

Редакция находится по адресу `/editor` и открывается без логина и пароля. Загрузка материалов, сбор новостей, обработка, правки, проверка и экспорт доступны в общем рабочем пространстве. HTTP-доступ к настройкам сервера, списку получателей и отправке писем закрыт. Ключи и SMTP задаются владельцем на сервере.

## Рабочий сценарий

1. Откройте «Открыть редакцию». Регистрация и вход не нужны.
2. Нажмите **Собрать новости** для актуальных публикаций подключённых источников. Также доступны импорт JSON/JSONL/CSV/TXT/HTML/DOCX/ZIP, текст и URL.
3. Проверьте группы событий, отбор и цитаты. Неподтверждённые данные и исключения отражаются в журнале.
4. Откройте дайджест, письмо и пост. Можно редактировать текст, менять порядок, объединять и разделять группы. После изменения нужна повторная проверка.
5. Утвердите выпуск. Скачайте ZIP/EML; письмо можно отправить из своего почтового клиента.

При первом запуске включены проверенные RSS SecurityLab, CNews и Хабра, почасовой сбор и ежедневный черновик в 09:00 МСК. Остальные источники включаются редактором. Состояние RSS не гарантирует качество любых будущих публикаций.

Демонстрационный вход, загрузка вымышленных новостей и тестовые сценарии в рабочем интерфейсе отключены. Автоматизированные regression tests сохранены в исходниках; они не загружаются в рабочую базу.

## Запуск

Локально Windows: заполнить .env по .env.example, затем выполнить `powershell -ExecutionPolicy Bypass -File infra/scripts/start-local.ps1`. Адрес http://localhost:6752, отдельный PostgreSQL проекта. Остановка: infra/scripts/stop-local.ps1, поддерживает -WhatIf.

Docker локально: `docker compose up --build -d`. Сервер с HTTPS: [README-deploy.md](README-deploy.md).

## Конфигурация

Секреты, локальная база, логи и backups исключены из Git и Docker build context. Не публикуйте .env.

GigaChat: GIGACHAT_AUTH_KEY, GIGACHAT_SCOPE=GIGACHAT_API_PERS, GIGACHAT_MODEL=GigaChat-2-Pro. Модель выбирается из реально доступных аккаунту. OAuth и токены только на сервере. TLS verification включена; публичный российский CA подключён только к клиенту приложения.

Gmail: SMTP_HOST=smtp.gmail.com, SMTP_PORT=465, SMTP_SECURITY=ssl, SMTP_USERNAME, SMTP_PASSWORD (пароль приложения), SMTP_FROM. Также поддерживается STARTTLS на 587.

В открытой редакции отправка через SMTP и автоматическая рассылка отключены. Адреса из новостей не становятся получателями. Расписание создаёт черновик, предпросмотр письма и EML доступны без входа. Закрытые почтовые настройки не выдаются через HTTP.

Сессионная cookie хранит только токен защиты действий от посторонних сайтов; она не является учётной записью. Сохраняются ограничения очереди, загрузок и сетевого сборщика. После достижения PUBLIC_MODEL_CALL_LIMIT обращений к модели за московские сутки новые запуски из браузера отклоняются; просмотр и экспорт доступны.

INITIAL_SOURCE_NAMES применяется при создании источников, DAILY_SCHEDULE_ENABLED — при создании первого расписания. Последующие настройки сохраняются в БД. ENABLE_DEMO=false оставляйте в рабочей среде.

## Проверки

Backend: из backend выполнить `../.venv/Scripts/python.exe -m pytest -q` (Windows). Frontend: npm run typecheck, npm run build, node --experimental-strip-types tests/counter.cjs.

Период start < published_at <= end, 24 часа до контрольного времени МСК. Дата без времени и неподтверждённое обновление исключаются. Каждый факт связан с цитатой/offsets; проверяются ID, числа, источники и лимиты 4000/2000. Пост использует принятые факты полного текста, оговорки сохраняются в обоих форматах.

GigaChat выполняет классификацию, извлечение, группировку, отбор, написание и отдельную смысловую проверку. Модель может ошибаться, утверждение редактором обязательно. Стоимость не вычисляется без достоверного тарифа; usage сохраняется при наличии.

Очередь PostgreSQL поддерживает идемпотентность, checkpoints и восстановление. Один worker; горизонтальное масштабирование не заявляется. Сбор соблюдает robots, ограничения частоты/размера и SSRF-защиту. Paywall/CAPTCHA не обходятся.

Официальный набор организаторов не предоставлен, прохождение на нём не заявляется. Архитектура: docs/architecture.md.
