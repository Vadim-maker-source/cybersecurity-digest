# КиберСводка

Цель: подготовить проверяемый суточный дайджест по кибербезопасности из набора организаторов или согласованных источников.
Читатели: руководители и специалисты ИБ. Пользователь интерфейса: редактор.
Основной сценарий: импорт → контрольное время МСК → обработка → группы событий → проверка фактов → письмо/пост → экспорт.
Стек: Next.js, FastAPI, PostgreSQL, SQLAlchemy, GigaChat, Docker Compose, Nginx.
Критерии: до пяти событий, точные границы периода, подтверждение facts/evidence, 4000/2000 знаков без URL, восемь обязательных сценариев, честные результаты.
Дизайн: светлый рабочий кабинет, глубокий синий sidebar, нейтральные поверхности, индиго акцент, плотность достаточная для редакции, понятные русские статусы. Приоритет: provenance и объяснения.
Допущение: бренд не предоставлен, используем «КиберСводка»; набор организаторов пока не предоставлен.
Ограничения: только локальный запуск. Удалённый deploy подготовить, не выполнять. Тестовая отправка только на заданный allowlist.
Риск: внешние сайты и GigaChat могут быть недоступны. Показывать реальное состояние; fixtures не выдавать за live.
