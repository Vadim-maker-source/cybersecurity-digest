# Проверка дизайна

Основа: design/context.md. Локальная среда, редакционный кабинет, интерфейс на русском, реальные данные через API.

Проверено браузером: вход редактора, загрузка fixtures, создание выпуска, состояние очереди, навигация, реальные источники/настройки, выбор модели, запуск проверок, список выпусков, полный текст, пост и его копирование, письмо в iframe, evidence и скачивание ZIP. Модальное окно поддерживает Escape, удержание фокуса и возврат фокуса. При ширине 390 px горизонтального переполнения нет, мобильное меню открывается и закрывается. Временный viewport возвращён к исходному.

Светлая тема, согласованные отступы, sidebar, таблицы и карточки. Второстепенный текст и статусы усилены по контрасту. Пустые состояния и ошибки доступны. Цветовые статусы сопровождаются текстом.

Ограничение: полноценный screen-reader аудит не выполнялся. Наличие focus styles не считается полным соответствием WCAG.

Финальная проверка 14.10.2026: 23 backend unit tests, два теста счётчика, TypeScript и production build прошли. Восемь обязательных сценариев прошли отдельно через настоящий GigaChat и через детерминированный провайдер. Standalone Playwright suite подготовлен, но не запускался; фактический браузерный прогон выполнен через CUA.
